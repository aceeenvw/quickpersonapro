# ⊹ QUICK PERSONA PRO ⊹

Switch personas and manage their locks from the SillyTavern chat input.

## Features

- **Portrait picker:** Tap a portrait to switch. Search by name appears when you have more than eight personas.
- **Persona locks:** Tap **Chat**, **Character** (or **Group**), or **Default** to set that lock. Tap it again to release it.
- **Slash command:** `/qpp` toggles the picker. For example, `/qpp lock=chat Alex` switches to Alex and locks that persona to the open chat.

## Quick Start

In **Extensions → Install Extension**, paste `https://github.com/aceeenvw/quickpersonapro` and reload. Tap your avatar beside the chat input to open the picker. Tap outside or press Escape to close it.
